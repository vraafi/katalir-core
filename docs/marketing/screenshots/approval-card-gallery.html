Apa yang dikunci tes

  1. Kartu persetujuan dan kartu hasil tool benar-benar terlihat user (bukan hanya ada di cache).
  2. Args berasal dari server, bukan dari pesan user; body /chat/approve hanya token + keputusan.
  3. Output tool dirender untuk semua bentuk: string, {message}, dict JSON, dan kosong.
  4. Rincian alignment tersedia via <details> tanpa membengkakkan kartu.
  5. Galat server tidak mengunci kartu; cabang tetangga (credential_form, balasan success) tidak ikut rusak.
