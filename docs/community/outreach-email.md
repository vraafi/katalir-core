# Waiting-list email — Katalir

> **This is a waiting-list / launch-notification email.** It is sent only to
> people who explicitly asked to hear from us (they signed up themselves).
>
> It is **not** cold outreach. Do not repurpose it for the outreach shortlist in
> `outreach-sea.json` — that file holds public GitHub profiles and contains no
> contact details, precisely so that no unsolicited mail is generated from it.
> If you want to reach someone on that list, message them on GitHub and let
> them decide.

## Rules for sending

- **Opt-in only.** Send to people who signed up. Never to a scraped list.
- **One sender, one purpose.** No cross-promotion payloads in the body.
- **Unsubscribe in every message**, one click, no account required.
- **Say who we are** in the first two lines.
- **Do not send a "final" email to someone who never joined.**
