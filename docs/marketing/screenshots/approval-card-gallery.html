Apa yang dikunci tes

  1. Kartu benar-benar terlihat user (bukan hanya ada di cache).
  2. Args berasal dari server, bukan dari pesan user.
  3. Body /chat/approve hanya token + keputusan.
  4. Galat server tidak mengunci kartu, dan tidak disamarkan jadi pesan generik.
  5. Cabang tetangga (credential_form, balasan success) tidak ikut rusak.
